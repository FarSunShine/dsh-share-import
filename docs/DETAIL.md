# 分享链接导入

把一条公开的 DeepSeek 对话分享链接，直接变成 DSH 里的一个真实会话。

## 用法

1. 点击侧栏「新建会话」右侧的 ⤓ 按钮。
2. 粘贴形如 `https://chat.deepseek.com/share/<id>` 的链接（也可以只填 `<id>`）。
3. 选择目标工作区，点「导入」。

导入完成后侧栏会多出这个会话，标题取自原对话的第一条提问，99 轮问答、思考、联网搜索来源都会保留，可以直接往下提问。

## 它做了什么

- 链接通过官网公开接口 `https://chat.deepseek.com/api/v0/share/content?share_id=…` 读取，不需要登录、不需要 token、不需要先导出 ZIP。
- 转换后按 DSH 的会话种子格式写入，和官方「DeepSeek 会话导入」写出来的结构一致：每轮 `turn/start → step/start → user/message → assistant/message → step/end → turn/end`，导入过程不调用模型、不留下未结束的轮次。
- 导入完成后自动刷新会话列表。

## 限制

- **只支持公开且未过期的分享**。需要登录才能看的分享读不到。
- **导入的是静态历史**。它不是继续生成，原回答就是最终内容。
- **搜索来源会裁剪**：默认每条记录保留前 8 条结果、摘要截到 120 字符，避免一个几百轮的会话把上下文直接撑爆。可以在插件配置里改 `maxSearchResults`、`snippetChars`。
- **同一时间只允许一个导入**，并发请求会返回「正在导入」。
- **只支持 chat.deepseek.com**，豆包等其他站点暂不支持。
- 官网接口有速率限制，短时间连续导入可能返回限流错误，稍后重试即可。

## 配置

| 字段 | 默认值 | 含义 |
|---|---|---|
| `maxSearchResults` | `8` | 每条搜索记录最多保留的结果数 |
| `snippetChars` | `120` | 每条结果摘要截断的字符数 |
| `maxTitleBytes` | `80` | 导入标题的 UTF-8 字节上限 |
| `timeoutMs` | `60000` | 读取分享接口的超时时间 |

导入的会话内容属于原对话作者；请只导入你有权使用的内容。
